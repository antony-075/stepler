# MVP User Stories

## Admin

### A1 — Create collection
As an admin, I want to create a collection so I can gather content for an event.

### A2 — Share collection
As an admin, I want a default guest link and QR code so I can easily invite people.

### A3 — Configure visibility
As an admin, I want to control whether guests can see previous content.

### A4 — Manage links
As an admin, I want additional guest links with different permissions.

### A5 — Manage content
As an admin, I want to browse and delete collected content.

### A6 — Control access
As an admin, I want to revoke a guest link.

## Guest

### G1 — Open without account
As a guest, I want to open a shared link without creating an account.

### G2 — Upload photos
As a guest, I want to upload multiple photos quickly.

### G3 — Upload videos/documents
As a guest, I want to contribute other supported files.

### G4 — Submit text
As a guest, I want to submit a text contribution.

### G5 — View previous content
As a guest, I want to see existing content when the collection allows it.

### G6 — Delete my content
As a guest, I want to remove my own contribution when permitted.

### G7 — Understand failures
As a guest, I want clear feedback when something fails and an easy retry path.
