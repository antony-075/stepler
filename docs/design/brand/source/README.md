# Stepler brand assets

## Included

- `brand/logo-light.svg` — full logo for light UI.
- `brand/logo-dark.svg` — full logo for dark UI.
- `brand/logo-mark-light.svg` — transparent standalone mark.
- `brand/logo-mark-dark.svg` — transparent standalone mark.
- `brand/wordmark-light.svg` / `wordmark-dark.svg` — wordmark only.
- `icons/favicon.svg` — scalable favicon.
- `icons/favicon-16.png`, `favicon-32.png`, `favicon-48.png` — browser favicons.
- `icons/apple-touch-icon.png` — iOS/Safari home-screen icon.
- `icons/icon-192.png`, `icon-512.png` — PWA icons.
- `site.webmanifest` — PWA manifest.
- `brand/brand-colors.css` — core brand colors.

## Logo direction

The mark is a minimal tilted photo/polaroid, rotated 20° counter-clockwise,
held by a red pushpin, with a rounded geometric S.

Core colors:
- Stepler blue: #3657FF
- Stepler blue (dark): #4B68FF
- Pushpin red: #FF4F32
- Ink: #171A21
- Dark surface: #111318

SVG files have transparent backgrounds where appropriate and should be preferred
over raster assets whenever possible.
