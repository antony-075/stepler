# UI / Design

Use Tailwind + shadcn/ui + Radix.

No second component library without an explicit ADR.

Build accessible, responsive interfaces.

Design all meaningful states:
- loading;
- empty;
- error;
- success;
- disabled;
- permission denied.

No hover-only critical interactions.

Touch targets must work on mobile.

Reusable components need Storybook coverage.
