# Design Workflow

Use upstream design skills for design work. Do not invent a local replacement when an upstream skill covers the task.

For a new product/UI area, prefer this sequence when applicable:
1. design research / existing evidence
2. user journey
3. information architecture
4. design brief / visual direction
5. product/page/component design
6. critique + heuristics
7. accessibility
8. design-system gap analysis
9. frontend implementation
10. visual QA

The product must be responsive across mobile, tablet, laptop and wide desktop.

Stepler-specific design decisions belong in the project's design docs/tokens, not hidden inside a skill.
