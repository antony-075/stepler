# Code Review

Before completion, review the diff for:

1. correctness;
2. authorization/security;
3. data integrity;
4. API contract;
5. error handling;
6. performance/cost;
7. responsive/accessibility;
8. maintainability;
9. tests;
10. docs.

Look for:
- duplicated logic;
- dead code;
- unnecessary dependencies;
- hidden side effects;
- race conditions;
- unhandled retries;
- missing empty/error states;
- unrelated refactors.

Do not claim verification that did not happen.
