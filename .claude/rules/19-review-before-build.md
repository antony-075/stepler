# Pre-Implementation Gate

For significant features, before coding answer:

- What existing code handles something similar?
- What data changes?
- What API changes?
- What permissions change?
- What third-party services are involved?
- Does the frontend need a direct provider connection? If yes, why?
- What happens on retry?
- What happens on partial failure?
- What happens on deletion?
- What happens on expiration?
- What happens on mobile?
- How will it be tested?
- Is it MVP or Post-MVP?

If these questions reveal an unresolved consequential decision, ask the user before implementation.
