# Skill Source Policy

Do not present a hand-written local skill as community-verified.

Preferred source order:
1. official Anthropic skills/plugins;
2. established open-source repositories with meaningful adoption and active maintenance;
3. project-specific rules only when the rule is genuinely unique to Stepler.

When selecting a community skill, inspect repository activity, license, source instructions, overlap and maintenance before adoption.

Record upstream repository and path in `.claude/skills/UPSTREAM-SKILLS.md`.
